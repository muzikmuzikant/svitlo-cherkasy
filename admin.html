Швидкі інструменти

Зміни готуються у файлі «Ручні уточнення». Перед публікацією перевірте джерело й натисніть «Опублікувати через GitHub».

Не підтверджуйте фактичне знеструмлення конкретного будинку лише за загальним повідомленням для області.

Редактор та перевірка

Локальна копія

Рекомендуємо змінювати «Ручні уточнення»: інакше наступний імпорт може перезаписати графіки чи адреси. Для виправлення обов'язково залишайте посилання на офіційну публікацію.

Оберіть файл або підключіть сервер, щоб перевіряти дані.

Правила перевірки

Адреси з вулицями без будинків показують можливі підчерги, а не точні. Не позначайте аварійні повідомлення як активні без офіційного підтвердження. Автоматичні Push на заблокованому iPhone працюють лише при увімкненому push-сервері й дозволі користувача.
