VERSION CONTROL

Історія версій і відновлення

Повний журнал останніх 40 серверних редакцій. Можна повернути повідомлення й налаштування до обраного стану після підтвердження власника.

Відновлення не вмикає техроботи та не повторює старі Push. Перед ним зберігається поточна версія, тож зміни можна скасувати.

Крок 30 хвилин

Виберіть дату й підчергу. Натисніть на півгодинний проміжок, щоб відзначити відключення. Усі інші проміжки вважатимуться годинами без планових відключень. Після звірки з офіційним повідомленням можна опублікувати уточнення, яке не перезапише імпортер.

Без відключень Відключення

Увійдіть, щоб редагувати графіки.

Публікація в GitHub вимагає окремого налаштування GITHUB_TOKEN і GITHUB_REPOSITORY на Railway. Не позначайте неповну або непідтверджену новину як графік «на весь день».

Швидкі інструменти

Зміни готуються у файлі «Ручні уточнення». Перед публікацією перевірте джерело й натисніть «Опублікувати через GitHub».

Не підтверджуйте фактичне знеструмлення конкретного будинку лише за загальним повідомленням для області.

Редактор та перевірка

Локальна копія

Рекомендуємо змінювати «Ручні уточнення»: інакше наступний імпорт може перезаписати графіки чи адреси. Для виправлення обов'язково залишайте посилання на офіційну публікацію.

Оберіть файл або підключіть сервер, щоб перевіряти дані.

Правила перевірки

Адреси з вулицями без будинків показують можливі підчерги, а не точні. Не позначайте аварійні повідомлення як активні без офіційного підтвердження. Автоматичні Push на заблокованому iPhone працюють лише при увімкненому push-сервері й дозволі користувача.
