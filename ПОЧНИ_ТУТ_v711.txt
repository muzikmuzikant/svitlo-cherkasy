СВІТЛО ЧЕРКАСИ v7.1.1 — ЩО НАТИСКАТИ
=================================

Це накопичувальне оновлення від v7.0.0, v7.1.0 окремо встановлювати НЕ потрібно.

1) Завантажте svitlo-cherkasy-v7.1.1-update-from-v7.0.zip та розпакуйте.
2) Відкрийте GitHub → muzikmuzikant/svitlo-cherkasy → Add file → Upload files.
3) Перенесіть ВМІСТ розпакованої папки (не сам ZIP), зберігаючи структуру .github/, scripts/, tests/, push-server/.
4) Натисніть Commit changes.
5) GitHub → Actions → Publish Svitlo Cherkasy PWA. Дочекайтеся зеленого статусу.
6) GitHub → Actions → Update official blackout data → Run workflow. Дочекайтеся результату.
7) Відкрийте на GitHub data/schedules.json: у масиві days має з'явитися потрібна дата (якщо офіційний графік опубліковано й імпортер його розпізнав). Якщо не з'явилася — відкрийте логи Update official blackout data, не вигадуйте відсутні години.
8) Railway → Deployments: переконайтеся, що останній коміт розгорнуто. При оновленні немає потреби змінювати ADMIN_PASSWORD, APP_ORIGIN, SCHEDULE_URL або VAPID-ключі.
9) Відкрийте https://svitlo-cherkasy.pp.ua/admin.html → Увійти → Редактор → Конструктор графіків.
10) Виберіть дату, підчергу, натискайте на 30-хвилинні клітинки, вставте посилання на ПІДТВЕРДЖЕНИЙ офіційний графік цієї дати.
11) Натисніть Підготувати зміни. Для прямої публікації з адмінки потрібні змінні GITHUB_TOKEN та GITHUB_REPOSITORY у Railway. Вони секретні, не додавайте токен на GitHub Pages. Якщо їх немає — скористайтеся «Експортувати JSON» і завантажте файл data/manual_overrides.json у GitHub самостійно.

Важливо: архів оновлення не містить data/, CNAME або push-config.json. Не видаляйте їх із репозиторію.
Якщо підчергу не названо у ПОВНІСТЮ ПІДТВЕРДЖЕНОМУ списку оператора, її планові відключення на цей день відсутні. Це не гарантує безперервного фактичного електропостачання.
