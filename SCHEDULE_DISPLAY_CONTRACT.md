# Незмінне правило відображення графіків у «Світло Черкаси»

## Вимога власника проєкту (15 жовтня 2026)

**ЯКЩО ДЛЯ ДАТИ НЕМАЄ ОПУБЛІКОВАНОГО ГРАФІКА, У ЗАСТОСУНКУ ПОКАЗУВАТИ «СВІТЛО ВЕСЬ ДЕНЬ».**

Це усталена продуктова поведінка, погоджена власником. Не підміняти її на «Невідомо» або «Немає підтверджених даних» за відсутності графіка. Не додавати до неї умови свіжості джерела, успішності імпорту, горизонту дат чи наявності `confirmedNoScheduleDates`.

- Для кожної підчерги без опублікованого графіка показувати 24 години зеленого кольору, без планових відключень.
- Правило стосується сьогодні, завтра та будь-якої іншої вибраної дати, навіть коли перевірка джерела застаріла.
- Якщо для дати є опублікований графік, завжди відображати його години. Недостовірну частину **опублікованого** неповного графіка можна показувати невідомою, не підмінюючи графік.
- Повідомлення про несвіжі дані або помилки синхронізації можуть з'являтися окремо; вони не змінюють візуальне правило для дати без графіка.
- Назва «Світло весь день» означає стан за *плановим графіком*, а не показник фізичного датчика на конкретній адресі.

Закріплено тестами `tests/test_forecast_v711.mjs` та `tests/test_verified_absence_and_publication.mjs`. **Не змінювати це правило без прямого прохання власника застосунку.**
