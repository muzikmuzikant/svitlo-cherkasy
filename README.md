# ⚡ Світло Черкаси — PWA (адреса + автоматичні графіки)

Незалежний **неофіційний** застосунок. Використовує опубліковані АТ «Черкасиобленерго» графіки та адресні переліки й **не перевіряє фактичну напругу у квартирі**.

## Нове у v5

- **Прибрано темну тему**: застосунок тепер у єдиному світлому стилі, без перемикача теми.
- **Прибрано видимі скролбари / смуги прокрутки** там, де вони лише заважали.
- **Оновлено UI**: чистіша головна, нові картки, м’якші анімації, чіткіші стани й мікротексти.
- **Нове лого й іконки**: більш акуратна стилізована блискавка.
- У погодинній сітці замість текстових символів використовується **намальована іконка блискавки**.
- Якщо адресу не знайдено, показується **кнопка переходу на офіційний пошук Черкасиобленерго**. Додаток також **копіює адресу в буфер обміну**, щоб її можна було швидко вставити.
- Підтримка сіл і селищ у формі збережена, але автоматичне визначення підчерги залежить від того, чи є для цього населеного пункту підтверджена адресна база у `data/addresses.json`.

## Що працює

- Кілька адрес із локальним збереженням.
- Автоматичне визначення підчерги, **коли є точний і однозначний збіг** в офіційних даних.
- Ручний вибір підчерги, якщо автоматичний збіг відсутній або неоднозначний.
- Сітка 24 години × 7 днів, статуси на сьогодні, найближча зміна.
- Автоматичне отримання графіків із локальним оновленням через Python або через GitHub Actions.
- Офлайн PWA з кешуванням останніх даних.

## Важливі обмеження

- Застосунок **не вигадує підчергу**. Якщо даних недостатньо, він пропонує ручний вибір або перехід на сайт Черкасиобленерго.
- Передача адреси на сайт оператора реалізована як **best effort**: застосунок відкриває офіційний пошук із параметрами та копіює адресу в буфер. Якщо офіційний сайт не підхопить параметри автоматично, адресу можна просто вставити.
- Для багатьох сільських адрес автоматичне зіставлення може бути відсутнім, якщо імпорт локальних адрес не сформував відповідну базу.

## Запуск на Windows

1. Розпакуйте архів.
2. Відкрийте папку `svitlo-cherkasy` у Провіднику.
3. Натисніть адресний рядок, введіть `cmd`, натисніть Enter.
4. Виконайте:

   ```cmd
   python -m pip install -r requirements.txt
   python local_server.py
   ```

5. Відкрийте **http://localhost:8000**.

Якщо `python` не працює, спробуйте:

```cmd
py -m pip install -r requirements.txt
py local_server.py
```

> ⚠️ `python -m http.server 8000` **не** запускає автоматичне оновлення графіків. Для цього використовуйте саме `local_server.py`.

## Публікація на GitHub Pages

1. Створіть репозиторій `svitlo-cherkasy`.
2. Завантажте **вміст папки проєкту** в корінь репозиторію.
3. Увімкніть GitHub Actions і GitHub Pages.
4. Запустіть workflow оновлення даних вручну один раз.
5. Опублікуйте сторінку через `main` → `/ (root)`.

## Як це працює

- `scripts/update_data.py` читає офіційні публікації графіків і формує `data/schedules.json`.
- Той самий скрипт читає PDF/переліки адрес і формує `data/addresses.json` для автоматичного зіставлення адрес із підчергами.
- `app.js` працює тільки з підтвердженими даними та показує fallback-сценарій, коли даних замало.
- Адреси користувача зберігаються тільки в `localStorage` браузера.
