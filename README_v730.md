# Світло Черкаси v7.3.0 — «Вхідні» і Центр керування

## Користувачам
- Вкладка **«Вхідні»** показує Push, зміни графіка власної підчерги, офіційні повідомлення оператора й оголошення сервісу.
- Дані центру повідомлень зберігаються на конкретному пристрої (IndexedDB). Прочитане можна очистити, а нове — відмітити як прочитане.
- Історія публікацій лишилася у згортаному розділі «Історія офіційних графіків».
- Великі технічні попередження не відображаються, якщо на поточну дату вже є підтверджений графік; при затримках/відсутності даних залишається зрозуміле повідомлення.
- Новий повноекранний режим техробіт. Він **вимкнений**, доки адміністратор явно його не активує.

## Адміністраторам
- В адмінпанелі з'являється вкладка **«Застосунок»**: техроботи (назва, опис, необов'язковий час завершення), перегляд майбутнього екрана, оголошення в Центрі повідомлень (тип, активність, термін дії, видалення).
- Операційні налаштування зберігаються **лише у Railway volume**, файл `app-config.json` поруч із підписками. API `/api/admin/app-config` потребує наявної авторизації. Публічний `GET /api/app-config` віддає лише активні актуальні оголошення та статус техробіт.
- Увімкнення режиму техробіт в адмінці вимагає додаткового підтвердження. Сам деплой нічого не закриває.
- Для роботи адміністративних можливостей потрібно розгорнути відповідну версію `/push-server` на Railway. Лише оновлення GitHub Pages недостатньо.
- Якщо Railway тимчасово недоступний, застосунок не приховується автоматично, а сайт продовжує працювати на збережених даних.

## Перевірки
`python -m pytest -q tests`; `python scripts/build_pages.py`; `node --test tests/*.cjs tests/*.mjs`.
Зміни користувацького сховища й VAPID-ключів не потрібні.
