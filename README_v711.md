# Світло Черкаси v7.1.1

Редактор графіків у **Адмінпанель → Редактор → Конструктор графіків**. Оберіть день і підчергу, натискайте на 30-хвилинні проміжки, вставте посилання на підтверджену публікацію оператора, натисніть «Підготувати зміни» та «Опублікувати». Щоб публікувати з адмінпанелі без GitHub вручну, в Railway повинні бути конфіденційна змінна GITHUB_TOKEN та GITHUB_REPOSITORY (owner/repo); секрети не розміщуйте в GitHub Pages. Редактор змінює лише manual_overrides.json, який має пріоритет над автоматичним імпортом. Якщо немає токена — можна експортувати JSON і вручну завантажити в GitHub.

Імпортер краще розпізнає підчерги з крапкою після номера, як «5.2. 12:00 - 14:00». Підчерги, відсутні в **повністю перевіреному офіційному списку** цієї дати, трактуються як 0 планових відключень. Це не гарантія фактичної наявності електроенергії за аварій чи інших обмежень. Неповні/зламані дані не повинні створювати фальшиве «світло на весь день».

Після коміту запустіть **Update official blackout data** у GitHub Actions, перевірте результат та файл `data/schedules.json` на потрібну дату. Не перезаписуйте `data/`, `push-config.json`, `CNAME` архівом оновлення.
