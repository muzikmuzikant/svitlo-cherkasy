# Правило нових функцій для «Світло Черкаси»

Постійна вимога власника (25.10.2026): **кожна нова користувацька можливість, яку можна незалежно вимкнути або налаштувати, має бути відображена в адмінпанелі в розділі «Функції» одночасно з її появою в UI.** Перемикач без реальної дії заборонений.

Для нової функції обов'язково:
1. Додати зрозумілу назву, опис і реальний checkbox у `admin-features.js`, у відповідну групу.
2. Додати ключ зі значенням за замовчуванням у `push-server/app-config.js` (`defaultSite().flags`), інакше Railway відкине ключ під час валідації.
3. Додати ключ в `site-mode.js` (`featureKeys`) для застосування класу `feature-off-<key>` у PWA.
4. Перевірити справжній вплив стану on/off на JS або CSS конкретної функції, у тому числі на вже відкритий екран, через `svitlo:public-config` за потреби.
5. Додати тести для вимкненого/увімкненого стану та змін посеред сеансу; зберегти доступність (keyboard/focus), темну тему, reduced-motion.
6. Оновити ключ SW cache в `sw.js` при зміні статичних файлів; не змінювати графіки, адреси, VAPID, маніфест PWA чи том Railway.
7. Головний екран і Налаштування не редизайнити без окремого доручення власника. Адміністративна вкладка «Функції» має містити керування, а не інформаційні заглушки.

Виняток: критично важливі безпекові функції, факт офіційного джерела, перевірка точності графіка та правила приватності **не можуть вимикатися** задля декоративного перемикача. Для них не додавати фальшивий контроль, а лише пояснення, якщо потрібне.

Нові ключі графіка 25.10.2026: `allQueues`, `allQueuesGroups`, `allQueuesCompare`, `allQueuesDetails`, `allQueuesRowIntervals` (типово вимкнено), `allQueuesNowMarker`, `allQueuesExport`; анімації: `microMotion`, `panelMotion`, `selectionMotion`. `animations` існував раніше.
