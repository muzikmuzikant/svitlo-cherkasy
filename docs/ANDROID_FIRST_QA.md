# Постійне правило QA для «Світло Черкаси»: Android перед iOS

Це обов'язкове правило всіх майбутніх змін. **Насамперед тестувати Android (Chrome, встановлена PWA)**, оскільки Android становить більшість користувачів. Потім iPhone (Safari/PWA), Samsung Internet, Firefox/Edge і десктоп.

## Матриця перевірок

1. Android Chrome як встановлена PWA: холодний запуск, офлайн, зміна мережі, Push і переходи з Push, системна кнопка «Назад», свайпи, клавіатура, нижня навігація.
2. Android Chrome як сайт: установка PWA та правильність інструкцій.
3. Samsung Internet: встановлення/ярлик і правильні підказки.
4. iPhone Safari та PWA: діалоги, safe area, Push, масштаб, клавіатура та темна тема.
5. Десктоп: доступність, вкладки, адміністрування, панелі, форми.

На всіх платформах тестувати 320/360/390/412/480 CSS px, світлу/темну теми, повільну мережу, відсутність мережі, порожню і заповнену базу адрес.

## Пріоритетні сценарії

- Відкрити кожну вкладку, перевірити Android Back і повернення на попередню вкладку.
- Створити/редагувати адресу, провести пальцем вниз від шапки або верхнього краю вмісту, перевірити скрол без стрибків.
- Відкрити всі внутрішні сторінки, повернутись Android Back без порожніх iframe.
- Перевірити повідомлення: список, читання, кнопка «Прочитати всі», фото, поширення, Push-переходи.
- Перевірити підтримку: нове звернення, приватні вкладення, чат, відновлення за номером і ключем.
- Перевірити Svitlo Office на Android: нижня панель, лічильник, звернення, редагування, клавіатура.
- Перевірити відсутність горизонтального скролу і перекриттів.
- Прогнати GitHub Actions staging-checks та offline-cold-start, включно з tests/android_pwa_browser.py.

## Релізні заборони

**Не змінювати main без прямого дозволу власника.** Усі нові зміни виключно в staging.
Не стверджувати, що Android/iPhone фізично перевірений, якщо пройшли лише Playwright/Chromium тести.
Не обіцяти Push/Telegram/медіа до фактичної перевірки бета-бекенда Railway.
Нові функції повинні бути без зайвого тексту розробників у релізних повідомленнях. Переходи плавні та короткі.
