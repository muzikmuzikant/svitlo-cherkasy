# Release review: 7.9.8

**Статус: НЕ СХВАЛЕНО ДЛЯ PRODUCTION.** Це кандидат у реліз. Не зливати PR до виконання всіх блокерів.

## Технічно підтверджено 16.10.2026

- Production GitHub Pages: `main`, домен `svitlo-cherkasy.pp.ua`; Google Search Console HTML-файл має залишитися у корені зібраного сайту.
- Production Railway: project `exciting-delight`, сервіс `svitlo-cherkasy`, окремий том `svitlo-cherkasy-volume` на `/data`, регіон `europe-west4-drams3a`.
- Beta Railway: project `svitlo-cherkasy-beta`, сервіс `svitlo-beta-api`, **інший** том `svitlo-beta-storage` на `/data`, регіон `iad`.
- Production cron: `svitlo-schedules-cron`, кожні 5 хвилин, без окремого тому.
- `main` має власні оновлення `data/schedules.json`, `data/emergency.json`, `data/source_review.json` та `google651cc9e5e29fd428.html`. Вони збережені.
- Production `CNAME`, `push-config.json`, `robots.txt` та `manifest.webmanifest` залишені з `main`; налаштування Beta у Production не переносилися.
- Реклама за замовчуванням вимкнена на новому бекенді, доки не затверджено відповідальну особу, контакти та правові підстави.
- Модальне підтвердження нових юридичних документів також вимкнено за замовчуванням до схвалення редакції.

## Обов'язкові перевірки перед злиттям

- [ ] Указати реального володільця персональних даних, стабільний контакт та процедуру запитів на доступ/видалення. Не вигадувати особу.
- [ ] Перевірити фактичні строки зберігання файлів: звернення, Push, агреговані події, псевдонімні PWA-ідентифікатори; включно з резервними копіями.
- [ ] Перевірити документи й підстави передачі/обробки через GitHub Pages, Railway, Apple/Google/Cloudflare; окремо перевірити умови реклами та приймання платежів.
- [ ] Підтвердити, що інсталяційний хеш і IP-derived короткострокова дедуплікація не називаються повністю анонімними даними; оновити політику за результатом рев'ю.
- [ ] Прогнати CI для PR: JS/Python регресійні тести, production build, контроль недоторканності даних.
- [ ] Перевірити на реальному iPhone встановлений PWA: оновлення Service Worker, швидкі тапи, анімації, відсутність горизонтального скролу, адмінку.
- [ ] Перевірити Push при повністю закритому PWA: попередження про відключення, повернення світла, екстрені події та **одне** повідомлення на подію (мінімум два пристрої).
- [ ] Перевірити фактичне отримання графіків із Production після майбутнього деплою, адмінавторизацію, рекламний центр і вимкнений default.
- [ ] Окремо схвалити автором зміни юридичних текстів і реліз до `main`; лише після цього вмикати рекламу в адмінці.

Автоматичні тести не підтверджують реальну доставку Push до закритого iOS PWA, юридичний статус або політики провайдерів.
