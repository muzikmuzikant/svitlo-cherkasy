# Перевірка перед публікацією юридичних оновлень

**Статус:** лише проєкт для рев’ю; не публікувати до заповнення пунктів нижче.

1. Визначити фактичного володільця персональних даних та контактний канал, через який користувач може реалізувати права на доступ, виправлення і видалення. Не вигадувати ПІБ, адресу, організацію чи email.
2. Підтвердити реальну конфігурацію Railway (том /data, строки зберігання звернень, Push) та GitHub Pages, перевірити місце обробки даних, договори та можливість міжнародної передачі.
3. Перевірити правову підставу для агрегованих лічильників вибраної підчерги/населеного пункту та чи потрібна окрема згода для юрисдикцій за межами України. Не класифікувати малу сільську групу як безумовно анонімну.
4. Перевірити події, що реально надсилаються: landing, app_open, install_guide, queue_sample, locality_sample, platform_sample, version_sample. Сервер має зберігати лише підсумкові годинні лічильники без IP, будинку, вулиці, GPS або device ID.
5. У звичайній адмін-аналітиці відображати категорії пристроїв, **не** повний User-Agent або точну модель телефону. Для населених пунктів із менш ніж 5 подіями за період приховувати назву й включати лише в "Інші".
6. У зверненнях діагностика надсилається лише за добровільною галочкою й лише у формі {platform,os,browser,appVersion}. Без галочки ці поля не зберігати. Експорт звернень в адмінці вважати конфіденційним.
7. Перевірити, що посилання на Політику конфіденційності, Умови користування, Джерела та Контакт працюють в PWA та на сторінці встановлення. Переконатися, що зміни відповідають актуальному стану застосунку.
8. Провести ручне тестування на iOS Safari: повторний тап тієї самої вкладки, швидкі тапи по різних вкладках, прямий перехід на графіки, зменшення руху, повернення з фону, перемикання без скролу/стрибка.
9. Прогнати усі automated tests, staging / build і security review. Не перемикати source Railway та не зливати PR у main без схвалення користувача.

Основні нормативні джерела для перевірки:
- [Закон України «Про захист персональних даних»](https://zakon.rada.gov.ua/laws/show/2297-17), насамперед статті 6, 8, 12, 29.
- [Закон України «Про інформацію»](https://zakon.rada.gov.ua/laws/show/2657-12).
- [Закон України «Про електронну комерцію»](https://zakon.rada.gov.ua/laws/show/675-19), якщо впроваджуватимуться оплатні послуги чи електронні договори.

Цей список не є висновком юриста й не гарантує відповідність кожній юрисдикції. Оператору потрібна перевірка перед реальним випуском.
