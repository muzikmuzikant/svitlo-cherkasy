# Світло Черкаси 7.2.1 — виправлення для чинного GitHub v7.2.0

Цей патч підготовлено для репозиторію `muzikmuzikant/svitlo-cherkasy` (стан v7.2.0), **а не Railway-чернетки**.

- Оновлені пости Черкасиобленерго виявляються за датою графіка та порядком новин.
- Новини з варіантами вступу більше не відкидаються лише через відсутність фрази «Години відсутності електропостачання».
- Нерозбірливі оновлення позначаються для конкретного дня; раніше підтверджений графік залишається офіційним, але може бути застарілим.
- Значення `reviewPending` залишається для діагностики, нове поле `unresolvedDates` є масивом дат.
- При оновленні не перезаписуйте `data/*.json`, `.env`, Railway Variables або `/data` volume.

Перевірка: `python -m pip install -r requirements.txt pytest`, `python -m pytest -q tests`, `python scripts/build_pages.py`, `node --test tests/*.cjs tests/*.mjs`.

Важливо: це оновлення не змінює архітектуру Railway та не гарантує, що поточний пост оператора доступний для автоматичного завантаження. Точність живого графіка потребує звірки з оператором.
