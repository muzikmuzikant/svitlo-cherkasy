СВІТЛО ЧЕРКАСИ v6.9.2 — ОРИГІНАЛЬНА ІКОНКА

1. Розпакуйте архів v6.9.2-update.zip. Відкрийте GitHub-репозиторій svitlo-cherkasy.
2. Завантажте файли з архіву ЗІ ЗБЕРЕЖЕННЯМ ПАПОК. Файли apple-touch-icon.png та apple-touch-icon-v692.png мають бути В КОРЕНІ, поруч із index.html; іконки у папці assets.
3. Commit changes, GitHub → Actions → Publish Svitlo Cherkasy PWA, дочекайтеся зеленого статусу.
4. Перевірте у Safari: https://svitlo-cherkasy.pp.ua/apple-touch-icon-v692.png — має відкриватися синя іконка з білою блискавкою без білої плями. Те саме для /apple-touch-icon.png.
5. Переконайтеся, що https://svitlo-cherkasy.pp.ua працює БЕЗ попередження про сертифікат: для PWA та Push потрібен HTTPS. Якщо GitHub ще видає TLS-сертифікат, дочекайтеся завершення.
6. На iPhone вже доданий ярлик може залишити стару літеру «С» через кеш iOS. Після появи справжньої іконки за посиланням відкрийте сайт у Safari → Поділитися → На початковий екран → Додати. Якщо старий ярлик не оновився, видаліть його й додайте знову (перед цим запишіть адресу/підчергу, може знадобитися повторно ввімкнути Push).
7. Railway, Push-ключі, ADMIN_PASSWORD та DNS НЕ змінюйте.

Це оновлення не замінює data/, push-config.json або CNAME.
