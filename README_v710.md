# Світло Черкаси v7.1.0 — встановлення та автоматичне оновлення даних

## Що змінилося

- Перероблено екран, який бачать користувачі у звичайному браузері. У встановленому PWA основна програма запускається як раніше.
- Для iOS інструкція встановлення показується одразу; Android Chrome використовує системний діалог, коли браузер його пропонує.
- На головному екрані встановленого PWA є рядок автоматичної перевірки: статус, дата останньої перевірки оператора й час останнього завантаження на телефон.
- Коли PWA відкритий, він перевіряє опубліковані дані при старті, при поверненні до застосунку й приблизно кожні 5 хвилин. При реальній зміні графіка обраної підчерги показує підтвердження.
- `Update official blackout data` у GitHub Actions перевіряє оператора приблизно двічі на годину, а `Refresh emergency bulletins` — приблизно чотири рази на годину. Час виконання GitHub може затримуватися; це не миттєва синхронізація.
- Коли імпортер не може отримати підтверджені дані, робота GitHub Actions тепер **червона**, а попередні перевірені графіки не затираються.

## Як оновити чинний проєкт

1. Зробіть резервну копію репозиторію. **Не видаляйте** `CNAME`, `push-config.json`, ваші актуальні файли `data/` і дані Railway Volume.
2. Розпакуйте `svitlo-cherkasy-v7.1.0-update.zip`, завантажте файли у корінь GitHub зі збереженням папок, натисніть Commit changes.
3. У `Settings > Pages` залиште `Source: GitHub Actions`, Custom domain: `svitlo-cherkasy.pp.ua`, Enforce HTTPS увімкнено.
4. Перевірте `Actions > Publish Svitlo Cherkasy PWA` — запуск зелений.
5. У `Actions > Update official blackout data` натисніть `Run workflow` **один раз** для первинної перевірки. Усі подальші перевірки запускаються за розкладом; перевіряйте їх у Actions.
6. На iPhone у встановленому PWA перевірте Опції → Перевірити оновлення застосунку. Повторно встановлювати PWA не потрібно. У головному екрані відображається стан графіків.
7. Railway та Push-секрети **не змінюйте** — серверну частину цей реліз не змінює.

## Що важливо знати

- Графіки публікує оператор. Програма не бачить фактичну напругу в будинку.
- При відсутності нових офіційних публікацій час **останньої перевірки** може оновлюватися, навіть коли самі інтервали графіка лишилися старими. Це нормально.
- Записи з помилковою датою й далі потрапляють на перевірку: вони не мають автоматично перезаписувати підтверджені графіки.
- Якщо імпортер червоний, перегляньте логи цього запуску; попередні перевірені графіки зберігаються.
- Поширення нового `release.json` і `sw.js` через CDN може зайняти деякий час.
