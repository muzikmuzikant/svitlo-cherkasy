# Світло Черкаси v7.1.5 — пошук адрес

Це **виправлення сценарію додавання адрес**, поверх v7.1.4. Воно не змінює графіки, схеми Push, API Railway, дані адрес або іконки.

## У чому була помилка

Офіційний адресний перелік має окремі дані для будинків (`keys`) та підказки підчерг цілої вулиці (`streetQueues`). Для багатьох сіл (зокрема Слободи) перелік містить тільки вулиці й підчерги, без підтверджених номерів будинків. Попередня форма все одно просила уточнити номер — хоча це не могло змінити результат.

## Що виправлено

- Чітка відмінність між точно підтвердженим номером і вуличною підказкою.
- Введений номер відразу змінює статус, навіть якщо в джерелі немає будинкових записів.
- Коли доступні точні записи, відображаються підказки номерів будинків і автоматично визначається підчерга для точної адреси.
- Якщо точного запису немає, застосунок не вгадує підчергу за номерами сусідів.
- У багаточергових вулицях без адресних записів вказано, що потрібна ручна перевірка, і показано можливі підчерги.
- Ручний вибір підчерги не скидається при наборі номера.
- Пошук враховує схожі латинські/кириличні літери у суфіксах номерів (наприклад 12-A та 12-А); дробові номери залишаються різними (14 і 14/1).
- Підказки вулиць ховаються після переходу до поля номера.
- Необов'язкову назву місця перенесено в кінець форми.

## Як оновити робочий сайт

1. Збережіть резервну копію репозиторію **Code → Download ZIP**.
2. Завантажте файли з `svitlo-cherkasy-v7.1.5-update.zip` до **кореня** GitHub-репозиторію, замінюючи відповідні файли (зберігайте шляхи).
3. Натисніть **Commit changes** і дочекайтесь зеленого GitHub Action **Publish Svitlo Cherkasy PWA**.
4. У встановленому застосунку відкрийте **Опції → Перевірити оновлення застосунку**. Перевірте додавання адреси.

**Не завантажуйте повний ZIP поверх чинного сайту без потреби**: він містить локальні початкові (placeholder) дані `data/addresses.json`, `data/schedules.json`. У ZIP-оновленні ці файли відсутні.

## Технічні перевірки

- Запустити JavaScript: `node --test tests/*.cjs tests/*.mjs`.
- Запустити Python: `python -m pytest -q tests`.
- Побудувати GitHub Pages: `python scripts/build_pages.py`.
- Статична PWA-архітектура та наявні `.github/workflows` не змінювались.

Адресні дані одержує окремий імпортер; якщо оператор не зазначив номери для певної вулиці, **автоматично визначити підчергу конкретного будинку неможливо** без додаткового достовірного джерела.
