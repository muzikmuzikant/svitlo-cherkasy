# Railway Cron для «Світло Черкаси»

Детальна інструкція у `RAILWAY_ПОЧНИ_ТУТ.md` в корені ZIP.

Цей сервіс **не змінює алгоритм розпізнавання графіків**. Він запускає поточний
`scripts/update_data.py`, завантажує свіжі JSON з GitHub до роботи та публікує
обидва оновлені файли **одним комітом** через GitHub REST API.

- Кожні 5 хвилин за `*/5 * * * *` (Cron Railway, UTC).
- Railway не гарантує запуск рівно за хвилиною і пропускає запуск, якщо попередній не завершився.
- Максимум 240 секунд на один запуск; після цього він припиняється з помилкою.
- Якщо графік не змінився, heartbeat публікується приблизно раз на 30 хвилин.
- Кожна реальна зміна викликає GitHub Pages deployment через звичайний `push` із PAT.
- Жодних приватних токенів чи секретів у коді, JSON або ZIP немає.

GitHub Actions для адрес та екстрених подій поки залишаються, щоб міграція не
вплинула на інші частини PWA.
