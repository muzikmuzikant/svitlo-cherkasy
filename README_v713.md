# Світло Черкаси v7.1.3 — календар через неділю та частіший автоімпорт

## Нове

- У деталях графіка календар показує **сім послідовних дат від сьогодні**, а не від понеділка до неділі. Тому **в неділю 11 жовтня видно понеділок 12 жовтня**.
- Кнопки «Сьогодні» і «Завтра», стрілки перегляду попередніх/наступних семи днів.
- «Найближча зміна» та головний статус використовують завтра, навіть якщо завтра починається новий тиждень. За опублікованим графіком 05:00 показуємо «05:00 завтра».
- Автоматичний графік джерела: **кожні 5 хвилин з 15:03 до 21:58 UTC** (влітку 18:03–00:58 в Україні), у всі інші години — **кожні 15 хвилин**. GitHub Actions може запускати завдання із затримкою або пропускати окремі запуски.
- Імпортер графіків відокремлений від щотижневого імпорту адрес. Помилка PDF-адреси не блокує новий графік; помилка окремої старої новини не блокує перевірені дні.
- Новий `scripts/publish_gate.py`: якщо новий графік або змінився статус достовірності — публікуємо негайно; коли змін немає — не запускаємо Pages щоразу, але приблизно раз на 30 хвилин публікуємо оновлений час перевірки.

## Встановлення через GitHub (рекомендовано)

1. Зробіть резервну копію поточного репозиторію (GitHub → Code → Download ZIP).
2. **Розпакуйте `svitlo-cherkasy-v7.1.3-update.zip`** на комп'ютері.
3. Завантажте в корінь репозиторію всі файли **зі збереженням структури папок** (`.github/workflows`, `scripts`, `tests`). На GitHub при заміні файлів підтвердьте Commit changes.
4. У GitHub → Actions дочекайтеся зеленого `Publish Svitlo Cherkasy PWA`.
5. У Actions → `Update official blackout data` → `Run workflow` → `Run workflow` запустіть вручну. Перевірте в логах `Import official schedules`, `Decide whether a site deployment is needed`, `Commit verified schedules`.
6. Якщо було опубліковано новий графік: у `data/schedules.json` має з'явитися день `2026-10-12` з `verified: true`. Після цього PWA зможе показати його на екрані «Графік» за кнопкою «Завтра».
7. У вже встановленому PWA відкрийте Опції → Перевірити оновлення застосунку. Наявні адреси та Push не потрібно скидати.

## Важливо

- **Update ZIP не містить папку `data/`, CNAME чи `push-config.json`**. Вони зберігаються в репозиторії користувача.
- **Не завантажуйте full ZIP поверх чинного публічного сайту без перенесення своїх даних.** Повний архів містить тільки стартові дані й не має ваших змінних середовища Railway.
- Частіші GitHub Actions не гарантують, що публікація оператора буде доступна негайно; треба дивитися журнал помилок і стан `data/schedules.json`.
- «Є світло» означає прогноз **за плановим графіком**, а не підтверджений фактичний стан електромережі.

## Перевірки

- `python -m pytest -q`
- `python scripts/build_pages.py`
- `node --test tests/*.cjs tests/*.mjs`
- Браузерна перевірка на ширині 320, 390 та 412 px: переходи з неділі на понеділок, наступне відключення завтра о 05:00, відсутність горизонтального прокручування.
